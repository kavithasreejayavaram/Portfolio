## ⚙️ Local Development & Setup

### Prerequisites
- Node.js 18+ installed
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/kavithasreejayavaram/portfolio.git

# Navigate into the project folder
cd portfolio

# Install dependencies
npm install

# Start the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to explore the portfolio interface.

### Build for Production
```bash
npm run build
```
